# CHOP

The sibling web app to SLICE.

**Status:** placeholder. Coming soon.

SLICE lives inside Ableton. CHOP lives in the browser — same agent fabric, different surface.

Planned:
- Browser-based chat that talks to the same local Collab-Hub server
- Streams the same `claudeStep` / `claudeCursor` events
- Read-only mirror for non-Ableton collaborators
- Optional: drag MIDI clips out of the browser into Ableton, or post directly via ableton-mcp
